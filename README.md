# Cristelle — Portfolio

A senior-style creative portfolio for a Full-Stack Developer × UI/UX Designer.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- No framework required

### Why no Bootstrap?

Bootstrap is **not necessary for this portfolio**. The layout is deliberately art-directed and relies on a small custom design system. Adding Bootstrap here would introduce generic defaults and extra CSS that do not improve the visual result.

The portfolio remains responsive without it.

## Visual direction

The redesign moves away from the previous muted “warm atelier” look into a more vibrant **editorial creative-tech** identity.

Palette:
- Ink — `#121312`
- Cobalt — `#3157FF`
- Coral — `#FF6B5E`
- Lime — `#C7E86B`
- Lilac — `#B8A7FF`
- Gold — `#D6A84A`
- Warm canvas — `#F7F3EA`

Typography:
- DM Serif Display — expressive editorial headlines
- Manrope — clean UI/body typography
- IBM Plex Mono — technical labels and code

## Important content note

The ZIP originally contained six visual assets, all belonging to the audiovisual project / related screens. The previous HTML referenced several `project-*.jpg` files that were not actually present.

This version does **not** invent or reference missing screenshots.

The audiovisual project uses the supplied screenshots as a real collage. The other projects use intentionally designed typographic/art-directed covers until their real screenshots are added.

- Responsive navigation with mobile menu

- Accessible focus states
- Active section navigation
- Reduced-motion support
- Code typewriter animation with a 6-second reading pause
- Scroll reveal animations
- Editorial project grid
- Art-directed project covers
- No broken image references
